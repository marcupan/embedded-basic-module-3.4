# Модуль 3.4: неблокуючий плеєр на зумері

Домашнє завдання курсу Embedded Basic, варіант 1: плеєр через LEDC із фіксованим тіком, без `delay` і без задач FreeRTOS.
Плата ESP32-S3-WROOM-1-N16R8, PlatformIO, Arduino.

Відео: [demo.mp4](demo.mp4)

## Схема

Розводка на макетці: [map.svg](map.svg).

```
GPIO15 -> S зумера
3V3 -> середній пін зумера
GND -> мінус зумера
GPIO18 -> 220 Ом -> LED -> GND  (показує, що цикл не блокується)
```

## Що робить

| Клавіша | Дія |
|---|---|
| `t` | постійні 3,3 В на S, тест зумера |
| `m` | мелодія старт / стоп |

Мелодія: масив нот `{частота, тіки}`, тік 50 мс, між нотами пауза в 1 тік, щоб однакові ноти не зливались. Частоту задає `ledcWriteTone`.

## Результат

- Тест `t`: короткий пік, потім тиша, отже зумер пасивний.
- `m`: 14 нот різної висоти, у лозі правильні частоти.
- LED блимає рівно під час мелодії, `m` зупиняє її одразу.

## Запуск

```
pio run -t upload -t monitor
```
